# Mackros 1.3 (Fabric 1.20.4)
Редактор построек + настоящие блоки: лифт, калькулятор, пульт, телепорт-плита, батут, ускоритель, вентилятор, магнит, лечебная плита, лампа, маркеры A/B, жезлы.
Меню: Right Shift. Вкладка творческого режима: Mackros.
Мод теперь нужен и на сервере, и в мире блоки пропадут, если убрать мод.
